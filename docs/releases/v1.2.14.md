# v1.2.14

## Compatibility

- Accepts legacy `channels.onebot.groupAllowFrom` configs as a deprecated alias for `channels.onebot.allowFrom`.
- Normalizes bare legacy group ids such as `"1007476107"` to `group:1007476107` while preserving already-qualified `group:*`, `private:*`, and wildcard `*` entries.
- Keeps `allowFrom` as the authoritative field when both `allowFrom` and `groupAllowFrom` are present.
- Declares `groupAllowFrom` in the channel manifest schema, including named account configs, so upgraded OpenClaw hosts can validate older configs instead of failing before the plugin loads.
