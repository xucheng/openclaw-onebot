# v1.2.15

## Compatibility

- Carries forward the legacy `channels.onebot.groupAllowFrom` compatibility from `v1.2.14`, now on top of the `v1.2.13` hardening baseline.
- Accepts `groupAllowFrom` as a deprecated alias for `channels.onebot.allowFrom`.
- Normalizes bare legacy group ids such as `"1007476107"` to `group:1007476107` while preserving already-qualified `group:*`, `private:*`, and wildcard `*` entries.
- Keeps `allowFrom` as the authoritative field when both `allowFrom` and `groupAllowFrom` are present.
- Declares `groupAllowFrom` in the channel manifest schema, including named account configs, so upgraded OpenClaw hosts can validate older configs instead of failing before the plugin loads.

## Release Alignment

- Keeps the `v1.2.13` safer defaults: explicit command authorization, opt-in CLI sync, disabled group auto reactions by default, staged media hardening, and optional OpenClaw peer dependency metadata.
- Supersedes `v1.2.14` for release consistency across npm, GitHub, and ClawHub artifacts.

- `npm run build` passed via ClawHub package staging.
- npm, GitHub, and ClawHub final publication should use `v1.2.15` as the aligned release.
